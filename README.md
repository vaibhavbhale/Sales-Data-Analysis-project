# Sales-Data-Analysis-project
Interactive Streamlit dashboard for analyzing large CSV/Excel sales datasets. Cleans raw data, applies aggregations, shows KPIs and charts, and exports insights to Excel/CSV for stakeholders

## ✨ Key Features

* **Automatic Column Detection & Data Cleaning**
  Detects inconsistent column names and standardizes them into a unified schema.

* **Revenue Trend Analysis**
  Generates insights by **month, region, and product** for better business decision-making.

* **Interactive Filtering**
  Filter data dynamically by **date range, region, and product**.

* **KPI Dashboard**
  Displays important metrics like:

  * Total Revenue
  * Total Quantity Sold
  * Number of Orders
  * Average Order Value (AOV)

* **Export Reports**
  Download:

  * Multi-sheet Excel reports
  * Filtered CSV datasets

* **Large File Support**
  Optimized to process **200MB+ sales files** efficiently.

---

## 🛠️ Tech Stack

* **Python** – Core programming language
* **Streamlit** – Interactive web application framework
* **Pandas** – Data cleaning and analysis
* **NumPy** – Efficient numerical operations
* **XlsxWriter** – Multi-sheet Excel report generation
