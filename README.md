# Sales-Data-Analysis-project
Interactive Streamlit dashboard for analyzing large CSV/Excel sales datasets. Cleans raw data, applies aggregations, shows KPIs and charts, and exports insights to Excel/CSV for stakeholders


✨ Key features:
• Automatic column detection & data cleaning
• Revenue trend analysis by month, region, and product
• Interactive filters for date, region, and product selection
• KPI dashboards with visual insights
• Multi-sheet Excel report export + CSV download
• Supports large files (200MB+) with optimized processing

Tech Stack: Python, Streamlit, Pandas, NumPy, XlsxWriter
